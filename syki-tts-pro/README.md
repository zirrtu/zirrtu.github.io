# SYKI-TTS Pro 自然语音试听

这是一个无需构建的静态网站。`index.html`、`assets/` 必须放在同一目录下。

## 发布到 GitHub Pages

1. 将本目录里的全部内容上传到 GitHub 仓库的默认分支根目录。
2. 在仓库的 Settings → Pages 里，选择从该分支的根目录发布。
3. 等 GitHub Pages 完成部署后，使用设置页显示的公开网址访问。

网站使用相对路径，不依赖服务端、外部字体或第三方播放器，既可直接打开 `index.html`，也可部署在项目子路径下。

`assets/audio/` 中的参考音色和八段试听音频来自原始 HTML，未进行音频转换；展示文字及 SS 数值与原始内容保持一致，仅将参考标签改为“参考音色”。

发布前请确认参考音色和试听音频具有对外公开的授权。
